# Oracle to Excel Email Automation

## Project Overview
This project automates the process of extracting data from an Oracle Database, generating Excel reports, and sending them via email using Python.

## Technologies Used
- Python
- Oracle Database
- SQL
- Pandas
- OpenPyXL
- SMTP

## Project Workflow
1. Connect to Oracle Database.
2. Execute SQL queries to retrieve loan data.
3. Process retrieved data using Pandas.
4. Generate an Excel report.
5. Send the Excel report via email.

## Key Skills
- Oracle Database Connectivity
- SQL Data Extraction
- Python Automation
- Excel Report Generation
- Email Automation
