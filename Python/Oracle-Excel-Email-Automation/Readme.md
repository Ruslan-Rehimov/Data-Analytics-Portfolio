
# Oracle to Excel Email Automation

## Project Overview
This project automates data extraction from an Oracle Database, generates Excel reports using Python, and sends the reports via email.

## Technologies Used
- Python
- Oracle Database
- SQL
- Pandas
- OpenPyXL
- SMTP

## Workflow
1. Connect to Oracle Database.
2. Execute SQL queries to retrieve loan data.
3. Process data using Pandas.
4. Generate an Excel report.
5. Send the Excel report via email.

## Key Skills
- Oracle Database Connectivity
- SQL Data Extraction
- Python Automation
- Excel Report Generation
- Email Automation
